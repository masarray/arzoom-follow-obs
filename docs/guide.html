ArZoom v0.7.0 setup guide

Install ArZoom, enable Scene Camera, and add Cinematic Spotlight.

The recommended workflow zooms the composed OBS scene, preserves the accepted Kinematic Smart Viewport, and optionally guides attention with a soft GPU Spotlight linked to Toggle Zoom.

Scene safety: ArZoom applies presentation transforms in the filter output. It does not persistently rewrite scene-item position, scale, rotation, bounds, or crop.

Before you begin

  • Windows 10 or Windows 11, 64-bit.
  • OBS Studio. Build baseline: OBS 31.1.1; v0.7.0 was also directly accepted on OBS 32.1.2 / D3D11.
  • For scene-wide pointer-driven behavior, use one visible top-level Display Capture whose monitor and transform can be resolved deterministically.
  • Download the latest ArZoom Windows installer.

1. Download and install

Download the latest Windows installer

Close OBS completely before running the installer. Standard OBS Studio and OBS Portable/custom roots are supported.

2. Prepare the presentation scene

Use one visible top-level Display Capture as the presentation owner. Fullscreen is simplest, but deterministic positive axis-aligned scaled/inset and crop-aware layouts are also supported.

Avoid double zoom: disable old per-source ArZoom filters while Scene Camera is active.

3. Enable ArZoom Scene Camera

  1. Open the scene you want to present.
  2. Choose Tools → ArZoom — Toggle Scene Camera.
  3. ArZoom creates/enables a managed ArZoom Camera scene filter when needed.
  4. Use the same command to disable it later.

4. Open Scene Camera settings

Choose Tools → ArZoom — Configure Scene Camera.

5. Start with the recommended camera settings

6. Enable Spotlight controls

In the ArZoom filter properties, enable Spotlight controls. The v0.7.0 recommended defaults are:

The Spotlight master remains Off until you enable it, so adding a fresh ArZoom filter never places the effect on-air automatically.

7. Understand Cinematic Spotlight with Zoom

Toggle Zoom ON starts the cinematic focus choreography: the aperture begins larger than the frame, closes smoothly to the focus Circle, and brings in the configured background dim gently. Toggle Zoom OFF reverses the motion and restores full bright context.

The animation is time-based and can reverse cleanly if you toggle Zoom again before it finishes.

8. Zoom In / Zoom Out is resize-only

v0.7.0 behavior lock: while Zoom is already active, Zoom + and Zoom − must not replay the cinematic iris. Camera magnification, Presentation Cursor, and Spotlight only grow or shrink smoothly.

9. Presentation Cursor

v0.7.0 defaults to ArZoom Classic Hand. Seven built-in cursor styles remain available. Cursor size follows the exact live camera zoom.

Avoid double cursor: when ArZoom Presentation Cursor is enabled, disable native cursor capture in the underlying Display Capture.

10. Assign presenter controls

Open OBS Settings → Hotkeys. Available controls include:

  • Toggle Zoom;
  • Hold Zoom;
  • Freeze Camera;
  • Toggle Smart Follow;
  • Zoom In / Zoom Out;
  • Reset / Full Frame;
  • Overview Peek;
  • Toggle Spotlight;
  • Hold Spotlight.

11. Test the complete presentation path

  1. Restart OBS after installation.
  2. Enable Scene Camera.
  3. Toggle Zoom ON and verify smooth camera + cinematic Spotlight focus.
  4. Press Zoom + several times; verify only smooth resize, with no iris replay.
  5. Press Zoom − several times; verify the same resize-only behavior.
  6. Toggle Zoom OFF and verify the normal cinematic opening back to full context.
  7. Move the pointer locally and across large distances; Smart Camera should stay calm locally and acquire meaningful relocation promptly.
  8. Change Presentation Cursor styles and confirm the preview remains healthy.
  9. Test Toggle/Hold Spotlight and confirm the Properties panel does not flicker/rebuild.
  10. Add webcam/logo/browser overlays and confirm composed content zooms together.

When pointer-driven behavior is intentionally unavailable

ArZoom never guesses capture ownership or unsupported geometry. Multiple ambiguous Display Captures, unproven rotation/skew/flips, unsupported bounds modes, unresolved nested capture ownership, or invalid geometry may intentionally disable pointer-driven mapping.

Presenter zoom, Freeze, Overview, Reset, and safe fixed framing remain available. P4.2 deterministic multi-capture target selection is future work.

Before recording or going live

  • Make a short local recording and watch it at normal speed.
  • Confirm old per-source ArZoom filters are disabled when Scene Camera is active.
  • Test presenter hotkeys for conflicts.
  • Check OBS Stats for rendering or encoding lag.
  • Keep a fallback scene without presentation zoom for important live events.
