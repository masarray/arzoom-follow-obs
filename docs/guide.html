ArZoom v0.6.0 setup guide

Install ArZoom and enable Scene Camera.

The recommended workflow zooms the composed OBS scene so Display Capture and overlays move together. v0.6.0 adds deterministic real-world scale/inset/crop mapping and the stable Kinematic Smart Viewport.

Scene safety: ArZoom Scene Camera applies presentation transforms in the filter output. It does not persistently rewrite scene-item position, scale, rotation, bounds, or crop.

Before you begin

  • Windows 10 or Windows 11, 64-bit.
  • OBS Studio; the current build baseline is OBS 31.1.1.
  • For scene-wide pointer-driven Smart Follow, use one visible top-level Display Capture whose monitor and transform can be resolved deterministically.
  • The latest ArZoom Windows installer.

1. Download and install

Download the latest Windows installer

Close OBS completely, including any tray instance, before running the installer.

The installer supports Standard OBS Studio and OBS Portable / custom OBS folder. A valid OBS root contains:

bin\64bit\obs64.exe

The package installs both the plugin DLL and its data files:

obs-plugins/64bit/arzoom.dll
data/obs-plugins/arzoom/...

2. Prepare the presentation scene

Use one visible top-level Display Capture as the presentation owner. A fullscreen capture is the simplest setup. v0.6.0 can also map deterministic positive axis-aligned scaled/inset placement and crop-aware layouts. Webcam, browser, logo, and nested-scene overlays may be composed with it and will zoom with the scene output.

Avoid double zoom: if this scene already has ArZoom attached directly to Display Capture or another source, disable that old per-source ArZoom filter while Scene Camera is active.

3. Enable ArZoom Scene Camera

  1. Open the scene you want to present.
  2. Choose Tools → ArZoom — Toggle Scene Camera.
  3. If no managed camera exists, ArZoom creates an ArZoom Camera filter on the current scene and enables it.
  4. Use the same Tools command again to enable or disable that managed Scene Camera.

4. Open Scene Camera settings

Choose Tools → ArZoom — Configure Scene Camera. ArZoom ensures the managed filter exists and opens the current scene's normal OBS Filters dialog.

5. Assign presenter controls

Open OBS Settings → Hotkeys and assign the controls you want. ArZoom supports:

  • Toggle Zoom — latched presentation zoom.
  • Hold Zoom — momentary zoom.
  • Freeze Camera — hold exact framing while the pointer moves elsewhere.
  • Toggle Smart Follow — suspend/re-enable pointer-driven framing while zoom remains active.
  • Zoom In / Zoom Out — live zoom steps.
  • Reset / Full Frame — safe return path.
  • Overview Peek — hold for exact 1× overview, release to restore the exact saved shot.

7. Understand the Kinematic Smart Viewport

ArZoom intentionally does not keep the mouse at exact center all the time. Local gestures stay calm. When pointer context leaves the useful viewport area, the Scene Camera begins following promptly, uses smooth jerk-limited acceleration, can cruise decisively for far movement, then applies precision braking when the final target becomes clear.

The accepted v0.6.0 behavior should feel continuous: no stop → restart → stop cadence, no repeated left/right or up/down searching after final pointer intent is known, and exact drift-free HOLD after framing completes.

8. Presentation Cursor

Choose one of the built-in ArZoom cursor styles if you want a larger, camera-aware presentation pointer. Built-in arrows own their arrow-tip hotspot; hand styles own their fingertip hotspot. Cursor size follows the exact live camera zoom.

Avoid double cursor: when ArZoom Presentation Cursor is enabled, turn off native cursor capture in the underlying Display Capture.

9. Test the complete presentation path

  1. Restart OBS after installation.
  2. Enable Scene Camera.
  3. Activate zoom and make small local pointer gestures; the viewport should remain calm.
  4. Move the pointer across a large distance at 2×, 3×, and 4×; the viewport should begin following promptly and keep pointer-loss intervals short.
  5. Reverse pointer direction once; the viewport should transition smoothly rather than oscillate.
  6. Stop after a far movement; the viewport should brake smoothly, find a useful near-centre context, and become completely still.
  7. Test Freeze, Smart Follow On/Off, Reset, Zoom +/−, and Overview Peek.
  8. Add a webcam/logo/browser overlay and confirm all composed elements zoom together.
  9. If using scale/inset/crop, test pointer mapping at the edges/corners of the presentation capture.
  10. Restart OBS and verify the managed Scene Camera and hotkeys remain usable.

When Smart Follow is intentionally unavailable

ArZoom never guesses capture ownership or unsupported geometry. Pointer-driven Scene Camera behavior may intentionally disable itself when there are multiple candidate Display Captures, unproven rotation/skew/flips, unsupported bounds modes, unresolved nested capture ownership, or invalid monitor/source geometry.

Presenter zoom, Freeze, Overview, Reset, and safe fixed framing can still work. Simplify the presentation mapping or use the per-source ArZoom Filter when appropriate.

Per-source mode is still available

If you only need one Display Capture and want the lightest possible setup, you may still add ArZoom - Smart Camera Zoom & Follow directly under Display Capture → Filters → Effect Filters.

Before recording or going live

  • Make a short local recording and watch it at normal speed.
  • Confirm old per-source ArZoom filters are disabled when Scene Camera is active.
  • Test all presenter hotkeys for conflicts.
  • Check OBS Stats for rendering or encoding lag.
  • For important live events, keep a fallback scene without presentation zoom available.
