FAQ

Before you install

Does Scene Camera modify my scene layout?

No. Scene-wide presentation transforms are applied in the filter output. ArZoom does not persistently rewrite scene-item transforms.

Does Spotlight activate automatically when I add the filter?

No. The master Spotlight controls remain Off by default. After you enable them, the recommended cinematic Zoom-linked behavior is ready.

What happens when I press Zoom + or Zoom −?

While Zoom is active, only magnification changes. The cinematic Spotlight iris does not restart.

Can Smart Follow work when Display Capture is not fullscreen?

Yes when one top-level Display Capture has a deterministic positive axis-aligned scaled/inset or crop-aware mapping. Ambiguous ownership still fails safe.

Is v0.7.0 stable?

Yes. The accepted candidate passed 19/19 deterministic tests, Windows build/package gates, and direct OBS trials including the D3D11 Spotlight/render fixes.

Does ArZoom collect telemetry?

No. ArZoom has no analytics service and does not transmit captured frames, cursor data, clicks, or settings.
