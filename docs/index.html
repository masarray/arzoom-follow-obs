GOOD TO KNOW

A few quick answers.

More details in the guide and troubleshooting pages.

Is ArZoom a standalone app?

No. ArZoom is a native plugin that runs inside OBS Studio on Windows.

Does it work directly inside OBS?

Yes. It adds presentation-camera controls to your existing OBS workflow.

How do I install it?

Close OBS, run the Windows installer, then reopen OBS and enable Scene Camera from the Tools menu. See the setup guide.

Can I change the pointer and Spotlight?

Yes. Choose from 13 pointer styles, adjust size and Spotlight focus, and turn on click feedback. Spotlight is off by default.

Is it free and open source?

Yes. ArZoom is free and its code is available on GitHub under GPL-2.0-or-later.
