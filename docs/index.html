Recommended v0.5.1 setup

Scene Camera in a few steps.

Install ArZoom

Close OBS and run the branded Windows installer. Standard and portable/custom OBS roots are supported.

Use one fullscreen Display Capture

This is the initial deterministic mapping supported for scene-wide pointer-driven Smart Follow.

Toggle Scene Camera

Choose Tools → ArZoom — Toggle Scene Camera. ArZoom creates a managed scene filter automatically.

Configure and assign hotkeys

Use Tools → ArZoom — Configure Scene Camera, then assign presenter controls in OBS Settings → Hotkeys.

Avoid double zoom / cursor

Disable old per-source ArZoom filters while Scene Camera is active; disable the native Display Capture cursor when using ArZoom Presentation Cursor.

FAQ

Before you install

Can I still use ArZoom directly on Display Capture?

Yes. The existing per-source ArZoom Filter remains available as the lightest Display Capture-only workflow.

Does Scene Camera modify my scene layout?

No. Scene-wide presentation transforms are applied in the filter output. ArZoom does not persistently rewrite scene-item position, scale, rotation, bounds, or crop.

Why can Smart Follow be unavailable in some scenes?

v0.5.0 only enables scene-wide pointer mapping when ArZoom can prove one fullscreen Display Capture mapping. Ambiguous transformed or multi-capture layouts fail safe instead of guessing.

Is v0.5.1 production-ready?

It is a public Windows release with deterministic gates and direct OBS trial work behind it. Wider OBS-version, GPU, mixed-DPI, and long-duration validation continues before v1.0.

Does ArZoom collect telemetry?

No. ArZoom has no analytics service and does not transmit screen or cursor data.
